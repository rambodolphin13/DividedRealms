Choose a base model

A custom look is a private copy of a client model with your own textures. Pick a base model with the body shape and animations you want, download its textures as templates, paint over them (same layout), and upload the results. The stock model is never changed.

Advanced: use your own NIF mesh

Only for a NetImmerse/Gamebryo .nif built for DAoC that uses the same skeleton and bone names as the base model (it borrows the base model's animations). Meshes from other games must be re-rigged to the DAoC skeleton first, or they will be invisible, distorted or crash the client.

Close the game and server first. The client's gamedata.mpk and figures/skins/skin099.mpk are backed up, and Uninstall restores them. Textures become DXT1 (no transparency), resized to the stock size.

Use on selected NPC sets the Model of the NPCs selected in 3D world (and clears their NPC template, which would override it). Click Reload textured view to preview it.
